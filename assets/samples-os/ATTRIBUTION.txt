What is used (excerpts made by tools/fetch_open_samples.py, then IMA ADPCM by tools/gen_samples.py):
  Synthesizers/RolandSynthesizers/Roland JV-2080/Samples/101_Bass.wav      C2 C3 C4 -> SAMPLE set 101 BASS
  Synthesizers/RolandSynthesizers/Roland JV-2080/Samples/4pole_Bass.wav    C1 C2 C3 -> SAMPLE set 4P BASS
  Synthesizers/RolandSynthesizers/Roland JV-2080/Samples/JUNO_Strings.wav  C2 C3 C4 -> SAMPLE set JUNO STR
  Synthesizers/Linn/LinnDrum/LinnDrum.nbkt   eight of its seventeen hits -> DRUM kit LINN (and SAMPLE set LINN)

The excerpts are not kept in this repository: this folder holds only this file. Run tools/fetch_open_samples.py
(it reads ../open-samples or OPEN_SAMPLES=path, else downloads the four files) before ./build.sh. A firmware image
built with them carries these sounds: give it away freely, but do not sell it as, or as part of, a sample product.
